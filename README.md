# Streak

Daily habit and mood tracker. React + Vite + Tailwind + Zustand + Recharts, installable as a PWA. No backend.

## Run locally
    npm install
    npm run dev          # open the printed Network URL on your phone (same Wi-Fi)

## Build and preview
    npm run build
    npm run preview

## Deploy
Push to GitHub, then import the repo on Vercel, Netlify, or Cloudflare Pages.
Build command: `npm run build`  Output directory: `dist`
Open the deployed HTTPS URL on your phone and choose "Add to Home Screen".
